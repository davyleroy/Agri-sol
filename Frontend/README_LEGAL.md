# 🌱 AgriSol - AI-Powered Crop Health Monitor

## 📋 Project Overview

AgriSol is a comprehensive AI-powered agricultural technology platform designed to revolutionize crop health monitoring and disease detection in Rwanda and beyond. The platform combines cutting-edge machine learning with user-friendly mobile technology to provide farmers with real-time insights into their crop health.

## 🎯 Project Scope

### Core Features

- **AI Disease Detection**: Real-time analysis of crop images for disease identification
- **Health Monitoring**: Continuous tracking of crop health trends and metrics
- **Location-Based Services**: Field-specific recommendations and mapping
- **Multi-Language Support**: English and Kinyarwanda interface
- **Admin Dashboard**: Comprehensive analytics and management tools
- **Real-Time Updates**: Live data synchronization and notifications

### Technical Stack

- **Frontend**: React Native with Expo
- **Backend**: Python Flask with ML models
- **Database**: Supabase (PostgreSQL)
- **AI/ML**: TensorFlow/Keras models for disease detection
- **Maps**: Leaflet (free) and Google Maps integration
- **Authentication**: Supabase Auth with email/password

## 🔧 Technical Architecture

### Frontend (React Native)

```
Frontend/
├── app/                    # Main app screens

├── hooks/                 # Custom React hooks
```
